## Mode V6 — Editorial + Brief

Write as an independent expert who actually checked things — the voice of a
reviewer with no stake in which brand wins.

Required structure, in this order:

1. **Comparison table first.** The page opens with the comparison, before prose.
   A reader who reads nothing else must still leave informed.
2. **Per-brand mini-table.** Each brand block carries its own compact table of
   the facts that matter, followed by prose that says something the table cannot.
3. **Real payout timelines.** Actual withdrawal windows per method. Any timeline
   not verified is **добавьте данные** — an invented "24-48 hours" is exactly the
   failure this mode exists to avoid.
4. **Honest licence rundown.** State what each licence actually covers and what it
   does not. Do not treat every licence as equivalent.
5. **Red flags section.** A real one. Name the things that would make you warn a
   friend away — slow payouts, hostile terms, unclear ownership. A red-flags
   section with no red flags in it destroys the credibility of the whole page.

Tone: measured, specific, willing to say a brand is weak. No promotional
superlatives. The reader should finish trusting the source, not the operator.
