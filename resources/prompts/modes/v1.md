## Mode V1 — Базовый (text_review)

A straightforward multi-brand review. This mode exists for volume: many simple
pages, produced fast, at predictable quality.

- Flat, predictable structure: intro → brand blocks → short conclusion.
- One block per brand, same shape for every brand.
- No SERP analysis was run for this mode — work only from the supplied data.
  Because of that, be *more* conservative about numbers, not less: if the human
  did not supply a figure, the sentence gets rewritten without it.
- Keep it tight. No padding sections.
