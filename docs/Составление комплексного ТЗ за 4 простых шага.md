# Составление комплексного ТЗ за 4 простых шага

## Шаг 1

Заполняем вводные данные в [конвейере](https://docs.google.com/document/d/1tH5CS3whv3VpHZFWhq3t1SFOD9FHfLtkNV_SuJIHyN8/edit?tab=t.0):

`#### Параметры контекста`

* `- **GEO:** [ВСТАВИТЬ РЕГИОН — например, UK]` — Прописываем двухбуквенное обозначение ГЕО (напр. PL / CA / UK)   
* `- **Язык:** [ВСТАВИТЬ ЯЗЫК — например, en-GB]` — Прописываем обозначение языка в формате lang—LANG (напр. en-GB / en-US / es-AR / pl-PL)  
* `- **Цель страницы:** [ВСТАВИТЬ ЦЕЛЬ СТРАНИЦЫ — например, стимулировать регистрации и депозиты, предоставить информацию для новых и опытных игроков]` — цель можно оставлять такую же, как прописана тут, либо дать бОльшую конкретику   
* `- **Основная тема / основной фокус страницы:** [ВСТАВИТЬ ОСНОВНУЮ ТЕМУ — например, Mostbet Login]` — сюда вставлять главный ключ для страницы  
* `- **Тип страницы:** [ВСТАВИТЬ ТИП СТРАНИЦЫ — например, главная / обзор / руководство / лендинг / служебная]` — в свободной форме прописать какая страница   
* `- **Тип сайта:** [ВСТАВИТЬ ТИП САЙТА — например, партнёрский казино-сайт]` — тут можно оставить как есть 

## Шаг 2

`#### Целевые поисковые запросы` — тут заполняем главные ключи, по которым будет идти анализ конкурентов (***не больше 10 плиз*** \- это размывает фокус; все ключи, которые нужно интегрировать в статьи, вставляются в самом конце в Этап 5 конвейера)

`[ВСТАВИТЬ ЗАПРОСЫ — по одному на строку, например:`  
`mostbet login`  
`mostbet login page`  
`mostbet account login`  
`mostbet sign in`  
`]`

## Шаг 3

Идем в Ahrefs или ваш любимый сеосодержащий продукт, идентичный натуральному, находим по основному ключу конкурентов в выдаче (например, по запросу *1win* в аргентинском гео можно выбрать прямых конкурентов, которые тоже работают по бренду) и вставляем их в раздел `#### Конкуренты на анализ:` Этапа 2 конвейера.

## Шаг 4

Создаём гуглдок с ТЗ, вставляем туда заполненный конвейер и передаём редактору.

Если у вас больше одного текста, то делаем несколько вкладок в одном доке (так легче, не нужно плодить кучу доков), именуем их по теме статьи (например, main, app, login и т.п.) и вставляем в каждую вкладку конвейер для нужной страницы с заполненными данными.

* ***Большая просьба ничего не менять в самом конвейере, не предупредив при этом Lead Editor\!***
