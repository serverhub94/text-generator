
Важно: для драйвера database значение DB_QUEUE_RETRY_AFTER должно быть строго больше значения $timeout в App\Jobs\RunPipeline (по умолчанию 3600). Рекомендуемое значение — 3700. Если retry_after меньше или равно $timeout, задача, выполняющаяся дольше $timeout, может быть помечена как брошенная и повторно взята другим воркером, что приведёт к двойной оплате прогона.
